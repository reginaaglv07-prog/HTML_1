# 🌐 Fundamentos de HTML5

¡Bienvenido/a al repositorio de **Fundamentos de HTML5**! 🚀 Aquí encontrarás una guía práctica y estructurada para aprender las bases del desarrollo web utilizando el lenguaje de marcado estándar de la Web.

---

## 📌 Contenido del Repositorio

- 🧱 **Estructura Básica:** Documentos, etiquetas raíz y metadatos (`<head>`, `<body>`, `<meta>`).
- ✍️ **Texto y Tipografía:** Encabezados (`<h1>`-`<h6>`), párrafos (`<p>`), formato e importancia semántica.
- 🔗 **Enlaces y Navegación:** Hipervínculos internos, externos y anclas (`<a>`).
- 🖼️ **Multimedia:** Inserción de imágenes (`<img>`), audio (`<audio>`) y video (`<video>`).
- 📋 **Listas y Tablas:** Ordenadas (`<ol>`), desordenadas (`<ul>`) y tablas de datos (`<table>`).
- 📝 **Formularios:** Captura de datos del usuario (`<form>`, `<input>`, `<button>`, `<select>`).
- 🏷️ **HTML Semántico:** Organización del contenido con `<header>`, `<nav>`, `<main>`, `<article>`, `<section>` y `<footer>`.

---

## 🛠️ Requisitos Previos

Para empezar solo necesitas:

1. 💻 Un navegador web moderno (*Google Chrome, Mozilla Firefox, Edge, Brave*).
2. 📝 Un editor de código como **Visual Studio Code**.
3. ⚡ La extensión **Live Server** (opcional, pero recomendada para ver cambios en tiempo real).
